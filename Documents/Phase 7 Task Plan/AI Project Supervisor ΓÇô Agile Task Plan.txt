AI Project Supervisor – Agile Task Plan




  AI Project Supervisor – Agile Task Plan
  Based on SRS v1.0, SDD v1.0 and the Phase 6 module structures | Draft for review


  1. How to use this plan
  This plan breaks the whole project into small tasks grouped into 2-week sprints (Scrum).
  Every task is meant to take 1 to 5 hours, so one person can finish it in a single sitting and
  show a working result. If a task grows past 6 hours, split it.


     Item                             Rule

     Method                           Agile / Scrum, 2-week sprints, one goal per sprint

     Task size                        1 to 5 hours; one task = one small, testable result

     Types                            BE = backend (Node/Express), FE = frontend
                                      (React), AI = Python AI service / ML / RAG, OPS =
                                      setup and deployment, DOC = documents

     Priority                         Must = needed for the project to work, Should =
                                      important, Could = if time remains

     Board columns                    Backlog, To Do, In Progress, In Review, Done

     Sprint rhythm                    Sprint planning (day 1), short daily check-in, sprint
                                      review and demo (last day), retrospective

     Order of work                    Foundation first (Module 0), then Modules 1 to 5 in
                                      lifecycle order, then hardening


  Definition of Done (applies to every task):

          Code works locally and follows the folder structure from the Phase 6 module
          documents.
          Inputs are validated and errors use the shared error format.
          A test or a manual check proves it works.
          Code is merged to the develop branch through a pull request.
          Any new config value is added to the .env.example file.

  Note: Hours are estimates. Adjust sprint length or scope to your real deadline and team
  size.
