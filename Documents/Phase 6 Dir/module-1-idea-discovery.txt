Module 1: AI-Powered Project Idea Discovery - Directory Structure

AI Project Supervisor (Module 1 of the larger platform) | Based on SRS v1.0 and SDD v1.0 | Draft for review

1. Module summary

  ---------------------------------------------------------------------------------------------------------------------------------
  Item                                                             Detail
  ---------------------------------------------------------------- ----------------------------------------------------------------
  Type                                                             Component 1 of 5

  Purpose                                                          Collects student needs through an AI conversation, researches
                                                                   trends, problems and existing solutions with RAG, and recommends
                                                                   ranked project ideas. A student who already has an idea can
                                                                   submit it directly.

  Principal output                                                 Researched and ranked project ideas; one selected idea.

  Actors                                                           Student, Team Leader, AI Supervisor

  Use cases                                                        UC-02, UC-03

  Workflows                                                        WF-03, WF-04, WF-05

  Requirements                                                     FR-DIS-001..020; BR-DIS-1..5; RAG-001..010; AIR (language model
                                                                   use); MLR-003 (M5 idea ranking); EIR-003

  MongoDB collections                                              discoveryProfiles, researchFindings, ideas

  API groups                                                       Discovery; Research and ideas
  ---------------------------------------------------------------------------------------------------------------------------------

2. How this module fits the repository

The platform is one Express API (modular monolith), one Python AI service and one React single-page app (SDD 6.2). This module is
therefore a set of folders inside those three applications, not a separate application. Each backend module folder holds its own
routes, controller, service, validators and models (SDD 6.5).

-   Backend (Node.js + Express): backend/
-   AI service (Python + FastAPI, Ollama, Scikit-learn, RAG): ai-service/
-   Frontend (React): frontend/

7. Dependencies on other modules

-   Module 0: authentication, project record, aiGateway jobs, notifications, audit.
-   Hands the selected idea to Module 2 (requirements analysis) through projects.selectedIdeaId.

8. Notes, assumptions and open points

-   SDD Table 33 lists no GET endpoints for the discovery profile or research findings, and does not name the endpoint that starts
    idea generation. The frontend needs them; proposed additions: GET /projects/:id/discovery/profile, GET /projects/:id/research,
    POST /projects/:id/ideas/generate (to be confirmed).
-   LangChain or LlamaIndex must be chosen once (RAG-009). SDD 5.8 suggests LlamaIndex as a starting point, to be confirmed by a
    prototype.
-   The embedding model and the vector store (Chroma or FAISS) are proposed dependencies, not SRS requirements (SDD Appendix A,
    item 12).
-   Selecting an idea does not finalize the project scope (BR-DIS-5).

9. Suggested build order

1.  Models and validators; discovery profile endpoints.
2.  AI chat endpoint and prompt; frontend chat and profile review.
3.  RAG pipeline (sources, chunking, embeddings, vector store, retriever, reference validation).
4.  Research job end to end; findings page with origin labels.
5.  M5 idea ranking; idea generation; comparison and selection.
6.  Direct idea submission path (WF-05) and unavailable-AI fallback (UC-02 A3).
